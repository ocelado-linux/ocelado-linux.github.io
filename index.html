Ocelado Linux

Steam Game Mode on openSUSE Tumbleweed, for handhelds and desktop PCs.

  • Boots straight into Steam, like a Steam Deck. Desktop Mode is one button away.
  • Rolling release with a read-only system: every update is a snapshot you can roll back from the boot menu.
  • Gaming kernels included: OGC for handhelds, linux-tkg with BORE for desktops.

What's inside

Game Mode and Desktop Mode

The handheld editions start in Steam's Game Mode through gamescope. Switch to Desktop from Steam's power menu, and use the Return to Gaming Mode icon to go back.

Updates you can undo

The system is read-only and updates with transactional-update. Each update becomes a new snapshot, applied on the next reboot. If something breaks, pick an earlier snapshot in the boot menu.

Kernels built for games

OGC, from the Open Gaming Collective, carries handheld fixes. linux-tkg brings the BORE scheduler and a 1000 Hz timer, built for x86-64-v2 and v3. The boot menu keeps the kernel you used last on top.

openSUSE Tumbleweed underneath

Ocelado is a small layer on top of Tumbleweed: same packages, same repositories, rolling updates. NTSYNC, BBR and a raised vm.max_map_count are set up for games.

Install

  1. Download the installer

    One ISO for every edition: ocelado-installer.

  2. Write it to a USB drive

    Use Fedora Media Writer, Impression, balenaEtcher or dd. Everything on the USB drive is erased.

  3. Boot from the USB drive

    On the Steam Deck, hold Volume Down and press Power, then choose the USB drive.

  4. Pick your edition and disk

    The installer erases the disk you choose. Create your user and wait for it to finish.

  5. Restart

    Handhelds go straight into Steam. Desktops install the linux-tkg build for your CPU on first boot and use it from the next restart.

Keep it updated

On handhelds, Steam shows system updates in its settings. Desktops update in the background. Either way, each update goes into a new snapshot. To update by hand:

sudo transactional-update dup
sudo reboot

To go back to the previous system, choose an older snapshot in the boot menu, then make it permanent:

sudo transactional-update rollback
sudo reboot

Install more apps from Flathub, or add system packages with sudo transactional-update pkg install.
